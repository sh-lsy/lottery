# 02. 数据采集与增量同步引擎 (Crawler & Sync Service)

系统内置双数据源与断点续抓机制，确保历史数据的完整性与增量更新的幂等性。

---

## 1. 数据来源与协议

1. **官方与公开权威数据源**：
   * 中国福彩官网数据接口（CWL Open Data API）
   * 500彩票网全量历史存档接口作为备选回退通道
2. **抓取覆盖范围**：
   * 从创刊第一期（`2003001`）至当前最新期（`2026122`），累计 **3,519 期**。
   * 包含每期开奖号码、销售额、奖池余额、一/二等奖中奖注数及单注奖金。

---

## 2. 幂等增量机制

1. **去重策略**：以 `issue_no` 作为唯一约束（Unique Constraint），入库时采用 `INSERT OR IGNORE` 或先查后插策略，杜绝重复数据。
2. **数据校验（Validation）**：
   * 红球数量严格为 6，数值范围 $[1, 33]$，且严格升序排列无重复。
   * 蓝球数量为 1，数值范围 $[1, 16]$。
   * 校验日期与开奖星期匹配性（双色球每周二、四、日开奖）。

---

## 3. CLI 命令调用

```bash
# 执行全量或增量同步
python -m backend.app.cli sync-history
```
终端将输出同步日志、新增期数、最新期号以及奖池金额。
