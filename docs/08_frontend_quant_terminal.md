## 1. 前端架构与设计哲学

`SSQ-Quant-System` 前端终端采用专业的 **暗黑量化交易终端（Dark Quant Terminal）** 视觉风格，致力于将概率统计学、离散组合数学特征与博弈对决推演过程直观呈现给量化研究员：
1. **暗黑模式原生沉浸设计**：全站默认且强制暗黑主题，杜绝页面闪烁；调色板采用金融终端高对比度配色（深蓝灰底板、高亮状态指示器）。
2. **极速交互与模块化解耦**：基于 Vite 6 ESM 极速热重载开发环境，拆分四大核心功能视图，图表与复杂表格均具备自适应重绘与响应式布局。
3. **严格的静态类型系统**：全站基于 TypeScript 严格模式开发，与后端 Pydantic v2 模型 100% 对齐，通过 `vue-tsc --noEmit` 保证零类型隐式推导。
4. **开箱即用代理集成**：Vite 本地开发服务器透明代理 `/api` 请求至 `http://localhost:8000`，支持本地独立联调或同源生产部署。

## 2. 视觉色彩系统与霓虹发光样式规范

### 2.1 暗黑终端基础色彩规范 (`tailwind.config.js` & `style.css`)
- **主画布背景 (Canvas Background)**: `#0b0f19` (深空深蓝黑)

- **卡片与工作面板底色 (Card Surface)**: `#182234` (Navy Slate)
- **边框与分割线 (Dividers & Borders)**: `#334155` (Slate 700)
- **主文案高亮 (Primary Text)**: `#f8fafc` (Slate 50)
- **次要标签文字 (Secondary Text)**: `#94a3b8` (Slate 400)

### 2.2 核心彩球视觉与霓虹发光状态

为实现核奖复盘中心与沙盒碰撞中极具冲击力的视觉反馈，系统定义了特异的霓虹发光状态：

1. **未中奖号码淡化态 (`.ball-missed`)**：
   采用低饱和度灰暗底色，透明度设为 40%，突出显示中奖球：
   ```css
   .ball-missed {
     opacity: 0.40 !important;
     filter: grayscale(80%) !important;
   }
   ```
2. **命中红球霓虹红发光态 (`.ball-red-hit`)**：
   球体采用高能亮红 `#ff4757`，叠加高斯扩散光晕，放大 1.08 倍：
   ```css
   .ball-red-hit {
     background: #ff4757 !important;
     color: #ffffff !important;
     box-shadow: 0 0 12px rgba(255, 71, 87, 0.85) !important;
     transform: scale(1.08);
     font-weight: bold;
   }
   ```
3. **命中蓝球电光蓝发光态 (`.ball-blue-hit`)**：
   球体采用激光电光青蓝 `#00d2d3`，搭配深黑字体与广域扩散辉光，放大 1.08 倍：
   ```css
   .ball-blue-hit {
     background: #00d2d3 !important;
     color: #0b0f19 !important;
     box-shadow: 0 0 12px rgba(0, 210, 211, 0.9) !important;
     transform: scale(1.08);
     font-weight: bold;
   }
   ```
4. **工位伪装模式 (Camouflage Mode)**：
   点击顶部 `🎭 工位伪装` 按钮，界面立即平滑切换为低饱和度纯灰阶金融 K 线/代码编辑器风格，淡化彩票特征。

## 3. 四大核心视图功能详解

### 3.1 视图一：全景历史数据与走势看板 (`/history`)
- **文件路径**: `frontend/src/views/HistoryView.vue`
- **核心功能**:
  1. **宏观 KPI 统计卡片**：展示官方最新期号、当前奖池滚存余额（如 `¥29.80 亿`）、前三热号红球与前三冷号红球。
  2. **红蓝球全量遗漏热力图 (`OmissionHeatmap.vue`)**：
     - 支持切换查看最近 30 期、50 期或 100 期；
     - 纵轴为期号时序，横轴为 1~33 红球及 1~16 蓝球；
     - 单元格数值代表遗漏深度，背景色通过冷温热阶梯渐变着色，中奖当期以加粗黑底高亮标示。
  3. **核心数学指标分布看板 (`IndicatorChart.vue`)**：
     - **红球和值分布直方图**：对比正态拟合曲线与理论经验分布；
     - **AC 值离散复杂度柱状图**：突出 AC $\ge 6$ 的合理组合区间；
     - **奇偶比与跨度区间环形/柱状图**：展示多维特征的均衡度。
  4. **全量历史开奖表格**：
     - 呈现期号、日期、星期、6红1蓝开奖球、和值、AC值、奇偶比及一/二等奖注数；
     - 支持通过球号快捷检索开奖记录；
     - 顶部配备“增量同步最新开奖”按钮，实时触发后端爬虫与缓存刷新。

---

### 3.2 视图二：AI 策略预测生成实验室 (`/predict`)
- **文件路径**: `frontend/src/views/PredictLabView.vue`
- **核心功能**:
  1. **多参数交互配置控制台**：
     - **目标期号与策略模型**：支持集中保本策略（`CONCENTRATED_BREAK_EVEN`）、分散基准策略（`DISPERSED_BASELINE`）、统计防线过滤模式（`STAT_FILTER`）及高阶概率打分模式（`ML_PROB`）；
     - **自适应进化动态开关**：开启后由系统根据近期回撤与开奖偏差自动覆盖超参数；
     - **统计防线滑块调节**：和值区间（默认 `[75, 135]`）、AC值下限（默认 `$\ge 6$`）、跨度范围（默认 `[18, 30]`）与奇偶比合法性勾选。
  2. **离线秒级量化推演**：
     - 点击“启动离线量化推演”，调用 `POST /api/v1/predict/generate`，在 100ms 内完成运算并渲染；
     - 展示 2 核心胆码 + 8 卫星候选拖码池，以及蓝球 TOP 3 置信度排名。
  3. **5 注精选候选推荐方案展示**：
     - 卡片式并排呈现 5 注号码，分别标注各注的和值、AC值、跨度、奇偶比及置信度得分；
     - 集中保本模式下高亮展示“3+2 蓝球集中博弈矩阵”与返奖覆盖测算（前 3 注返 15 元覆盖 10 元成本并盈利 5 元；后 2 注返 10 元保本）。
  4. **数学决策依据阐述**：
     - 内置 Markdown 卡片解析并渲染本次推演的数学与博弈决策逻辑。
  5. **一键入库持久化**：
     - 点击“保存方案至历史预测档案”，调用 `POST /api/v1/predict/save`，锁定为正式预测待核验批次。

---

### 3.3 视图三：历史预测档案与核奖复盘中心 (`/archive`)
- **文件路径**: `frontend/src/views/ArchiveReviewView.vue`
- **核心功能**:
  1. **投资收益与胜率大盘总览**：
     - 汇总累计预测批次、总注数、虚拟总投入、虚拟总派奖、净利润及模拟 ROI；
     - 统计历史单期保本达成率（保本率）与蓝球命中率；
     - 实时展示当前自适应引擎的生效模式（`CONCENTRATED` 3+2 集中 vs `DISPERSED` 5 互异）与冷温热打分权重。
  2. **三态过滤标签页**：
     - 支持快捷筛选 `全部批次 (All)`、`待官方开奖 (Pending)` 与 `已开奖核验 (Verified)`。
  3. **逐注高亮比对卡片与霓虹发光**：
     - 展开单期批次后，上方展示官方真实开奖红蓝球；
     - 下方列出预测的 5 注号码，**命中的红球呈现霓虹红发光高亮 (`#ff4757`)，命中的蓝球呈现电光蓝发光高亮 (`#00d2d3`)，未命中的号码以半透明暗色灰度呈现**；
     - 清晰标注单注命中形态（如“中 4+1 四等奖”、“中 0+1 六等奖”）、奖金数额及本期合计回报率。
  4. **自适应反思轨迹与手动核奖比对**：
     - 提供“立即核奖比对”按钮，对已开奖但未核对的批次一键执行官方 14 种奖级判定与自适应反馈循环；
     - 抽屉面板展示该批次的 AI 赛后反思记录与超参数漂移演化日志。

---

### 3.4 视图四：历史碰撞沙盒工具 (`/sandbox`)
- **文件路径**: `frontend/src/views/SandboxView.vue`
- **核心功能**:
  1. **交互式选号面板**：
     - 33 个红球与 16 个蓝球点选矩阵，内建严格上限校验（必须精确选中 6 个不同红球与 1 个蓝球）；
     - 支持“机选一注 (Random)”、“清空重选 (Clear)”及特性实时预览（和值、跨度、奇偶比）。
  2. **3,500+ 期毫秒级历史全量碰撞**：
     - 点击“执行全量历史碰撞”，调用 `POST /api/v1/backtest/sandbox/collision`；
     - 后端依托 `CollisionCache` 内存矩阵，**在 8.48ms 内** 完成全量比对并返回结果。
  3. **多维统计分析与奖级分解**：
     - **最高历史战绩徽章**：展示该注在历史上命中的最高奖级（如“一等奖 (Jackpot)”或“三等奖”）；
     - **奖级频次分布表**：列出 1~6 等奖各命中多少期，以及累计理论派发总奖金；
     - **假想历史回测回报率**：以每期投注 2 元为基准，测算若历史上每期均投注该号码的累计成本、净利润与历史 ROI。
  4. **四维数学分位数仪表盘 (Quantile Gauges)**：
     - 呈现该注在红球和值、AC值、极差跨度、奇数个数上的历史百分位（Percentile）；
     - 评估该注是属于“正常中位区间 (30%~70%)”还是“极端异常偏态”，提供直观的量化风险预警。
  5. **历史最高中奖期次追溯列表**：
     - 列出历史命中最高奖级的具体期号、开奖日期及详细命中了哪些红球和蓝球。

## 4. 依赖管理与构建运行指南

### 4.1 环境准备
- **Node.js**: `v20.x` 或 `v22.x`（推荐 `v22.19.0`）
- **包管理器**: `pnpm`（推荐 `v11.x`）

针对 pnpm v11 的安全构建白名单机制，已在 `frontend/pnpm-workspace.yaml` 中固化配置：
```yaml
onlyBuiltDependencies:
  - esbuild
  - vue-demi
```

### 4.2 安装与启动开发服务
```bash
# 1. 进入前端工程目录
cd frontend

# 2. 安装全部依赖
pnpm install

# 3. 启动 Vite 开发服务器 (支持热重载与反向代理)
pnpm run dev
```
开发服务器默认启动于 `http://localhost:5173`。所有发往 `/api/*` 的接口请求会自动代理转发至本地 FastAPI 后端 `http://localhost:8000`。

### 4.3 静态类型检查
```bash
cd frontend
pnpm run type-check
```
调用 `vue-tsc --noEmit`，验证所有 `.vue` 与 `.ts` 文件无语法或类型错误，严格实现 **0 errors**。

### 4.4 生产打包与制品预览
```bash
cd frontend
# 执行生产编译与静态打包
pnpm run build

# 预览生产产物
pnpm run preview
```
打包产物将输出至 `frontend/dist/`，包含高度拆分的静态 JS/CSS 资源：
- `assets/vue-vendor-*.js`：Vue, Vue Router, Pinia
- `assets/element-plus-*.js`：Element Plus 核心暗黑组件
- `assets/echarts-vendor-*.js`：ECharts 5.6 高性能图表引擎
- `assets/index-*.js` & `index-*.css`：应用业务逻辑与 Tailwind 编译样式
